メール公式チェッカー（Gmail用 Chrome拡張機能） 試作版 v0.8.0

■ できること
Gmail（パソコンのブラウザ版）でメールを開くと、本文の上に判定が表示されます。
  🟢 公式の可能性：高 … 送信元認証に合格し、差出人が公式ドメイン
  🟡 注意             … 判断材料が足りない、または気になる点がある
  🔴 危険             … なりすましの可能性が高い
「理由を見る」で根拠（認証結果・ドメイン・リンク・文面）を確認できます。

■ リンクのロック（v0.7で追加）
メール本文のリンクは、最初から「ロック」されていて、押しても開きません（🔒マーク付きで表示）。
  ・押すと、本当の行き先（ドメイン）とURLだけを表示します。表示されている文字と行き先が違うときは警告します
  ・「URLをコピー」で、行き先を確かめてから自分で開くこともできます
  ・開きたいメールは、判定欄の下の「このメールのリンクを有効にする」を押します（「危険」のメールは確認が出ます）
  ・ロックしない設定にもできます（拡張機能のオプション →「本文のリンクをロックする」）
ログインや支払いが必要なときは、メールのリンクではなく、公式アプリやブックマークから開くのがいちばん安全です。

■ 調べていること
1. 送信元認証（SPF・DKIM・DMARC）… Gmailの受信サーバーが記録した結果を「メッセージのソース」から読み取ります
2. 差出人ドメイン … 企業名を名乗っているのに公式ドメインでない／フリーメール／似せたドメイン（amaz0n、rakuten-card-security など）
3. 返信先が差出人と別ドメインになっていないか
4. リンク … 表示URLと実際の行き先の不一致、短縮URL、IPアドレス直打ち
5. 文面 … 「アカウントが停止」「24時間以内」「本人確認」などの典型表現
6. 取引先なりすまし（v0.2で追加）
   ・登録した取引先に似せたドメイン（yamada-shoj1.co.jp など）や、取引先名を名乗る別ドメイン
   ・いつもの取引先なのに、返信先がこれまでと違うドメインやフリーメールに変わった
     （取引先のメールアカウントが乗っ取られた場合の典型。差出人ごとの返信先をこのパソコンの中だけに記録して比べます）
   ・「振込先の変更」「下記口座へ」など、振込先・支払先の変更を求める文面
     → 正規の送信元からでも「電話など別の手段で確認を」と表示します
7. 確認済みの送信者 … 差出人名の横の青いチェックマーク（BIMI）があれば根拠として表示

■ 添付ファイルの注意（v0.8）
・添付ファイルの名前と種類を見て、危ないものに注意を出します。
　プログラム（.exe など）、Webページ形式（.html .svg など：開くと偽のログイン画面が出る手口）、
　ディスクイメージ（.iso .img）、マクロ付きOffice文書（.xlsm .docm など）、
　パスワード付きの圧縮ファイル（本文に「パスワード」「解凍」などがある .zip など）
・「請求書.pdf.exe」のような書類に見せかけた名前や、文字の向きを変える特殊な文字で拡張子を隠した名前は「危険」にします。
・中身がウイルスかどうかは調べていません。

■ 自分あてメールと、アドレス単位の信頼済み（v0.8）
・自分のGmailから自分あてに送ったメールは、送信元認証の記録が付かないため、これまで「注意」と出ていました。
　v0.8から「自分のアカウントから送ったメールです」と表示します。外から自分のアドレスを名乗った偽メールは、これまでどおり「危険」になります。
・Gmailなどフリーメールの相手は、ドメインではなくアドレス単位（例：yamada.taro@gmail.com）で信頼済みに登録できます。
　「gmail.com」を登録すると、Gmailを使う全員が信頼済みになってしまうので登録しないでください。

■ 「危険」と出た本物のメールについて（v0.7.1）
会社がキャンペーン用に、公式の名前に言葉を足した別ドメイン（例：microsoftrewards.com）を使うことがあります。
送信元の認証に合格していて、ほかに怪しい点がない場合は、「危険」でも「〜を信頼済みにする」ボタンが出ます。
会社の公式サイト（メールのリンクではなく、自分で開いたページ）で本物と確認できた場合だけ追加してください。

■ 重要マークについて
受信トレイの矢印形のマーク（重要マーク）は、Gmailが「重要そう」と判断した印で、公式の証ではありません。
公式の目印は、メールを開いたときに差出人名の横に出る青いチェックマークです。

すべてブラウザの中で処理し、メールの内容を外部に送ることはありません（通信するのはGmail自身のページだけです）。

■ インストール方法（5分）
1. このフォルダ（mailcheck-ext）を好きな場所に置く（例：ドキュメント）
2. Chromeのアドレス欄に chrome://extensions を入力して開く
3. 右上の「デベロッパー モード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」を押し、このフォルダを選ぶ
5. Gmailを開き直す（すでに開いていたら再読み込み）
※ 新しい版に入れ替えたときも、Gmailのタブを再読み込み（Ctrl+F5）してください。判定欄の右上に表示される版番号で、新しい版が動いているか確認できます。

■ 取引先の登録（おすすめ）
chrome://extensions → この拡張機能の「詳細」→「拡張機能のオプション」で、
「取引先名,ドメイン」の形で1行に1社ずつ登録します。例：山田商事,yamada-shoji.co.jp

■ 信頼済みドメインの追加
公式なのに「注意」「危険」と出る会社がある場合（登録リストにない会社・取引先など）：
・判定欄の「〜を信頼済みにする」ボタン、または
・chrome://extensions → この拡張機能の「詳細」→「拡張機能のオプション」
から追加できます。本物と確認できたドメインだけを追加してください。

■ 限界（必ずお読みください）
・判定は目安です。「危険」と出たメールのリンクは開かず、公式アプリやブックマークから確認してください。
・企業の本物のメールアカウントが乗っ取られた場合は、認証に合格するため見分けられません。
・公式ドメインのリスト（domains.js）に無い会社は「登録済みの公式ドメインではない」と出ることがあります。
・Gmailの画面の作りが変わると、表示されなくなることがあります（その場合は連絡ください）。
・Gmailのスマホアプリ、Outlook、Yahoo!メールなどには対応していません。
・デベロッパーモードの拡張機能なので、Chrome起動時に注意表示が出ることがあります。
